# Contributing

Start with a small issue and a short-lived branch from main. Keep changes scoped and name commits using Conventional Commits. Run all checks in the README. Include regression coverage for state transitions, authorization, upload boundaries or retry changes. Use synthetic fixtures only. Submit material changes for review. Maintainers use semantic versions, an updated changelog, reviewed merges and annotated release tags. Follow CODE_OF_CONDUCT.md and SECURITY.md.
